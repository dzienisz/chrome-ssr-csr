What is shared when this is on

The domain name (never the full URL), the render type and confidence, detected frameworks, performance metrics, and a country derived server-side from the request IP, which is not stored.

Never shared: page content, personal information, browsing history, response headers, or the region breakdown shown in the Regions tab — that analysis stays on your device.
